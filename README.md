# Pivot into Tech: facilitator pack

Put every file in this folder in the same folder of your GitHub repository, then turn on GitHub Pages.

| File | What it is |
| --- | --- |
| `facilitatordesk.html` | The Facilitator Desk. Open this one. |
| `Pivot-into-Tech-Facilitator-Deck.pptx` | The 27-slide deck with speaker notes. |
| `Session-Analysis-and-Persona-Walkthrough.docx` | Timings, persona walkthrough, risks, Joe's review. |
| `01_MindForge.html`, `02_LoomSTEM.html`, `03_heist.html`, `04_compound_click.html` | The four games. Add them to the same folder so the Desk buttons open them. |

The Desk links to the other files by plain file name, so they must sit next to it.
Before the day, replace `[Contact name or team]` and `[Follow-up link]` on the "Next steps" slide.
